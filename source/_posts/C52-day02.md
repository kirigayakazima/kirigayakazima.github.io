<h2 id="定时器">定时器</h2><h3 id="工作方式">工作方式</h3><ol>
<li><p>interrupt0，13位，当 INT0 引脚由高电平变为低电平时触发中断。</p>
<ul>
<li>$X&#x3D;8192-N\frac{12}{fosc}$</li>
<li><strong>上次计数为0，要重复计数需要置零</strong></li>
</ul>
</li>
<li><p>interrupt1，16位，当定时器 0 计数器溢出时触发中断。</p>
<ul>
<li>$X&#x3D;65536-N\frac{12}{fosc}$</li>
<li><strong>上次计数值为0，要重复计数需要重置初值</strong></li>
</ul>
</li>
<li><p>interrupt2，8位自动重置定时&#x2F;计数器，当 INT1引脚由高电平变为低电平时触发中断。</p>
</li>
<li><p>interrupt3，8位，只有T0才能使用，当定时器 1 计数器溢出时触发中断。</p>
<ul>
<li>$X&#x3D;256-N\frac{12}{fosc}$</li>
<li><strong>计数器自动配置初值，不需要用户重置</strong></li>
</ul>
</li>
<li><p>interrupt4，串口中断，当串口接收完成（RI）或发送完成（TI）时触发中断。</p>
</li>
</ol>
<h3 id="TMOD-寄存器">TMOD 寄存器</h3><p>TMOD 的低 4 位控制定时器 0，高 4 位控制定时器 1，每个定时器都有两个工作模式可以选择</p>
<p>M0表示定时器0，M1表示定时器1</p>
<p>TMOD&#x3D;0x20表示定时器1设置为2模式</p>
<p>TMOD&#x3D;0x02表示定时器0设置为2模式</p>

<h3 id="TH和TL寄存器">TH和TL寄存器</h3><ol>
<li><code>TH0/TL0</code>表示定时器0的高低八位</li>
<li><code>TH1/TL1</code>表示定时器1的高低八位</li>
</ol>
<h3 id="IT寄存器">IT寄存器</h3><ol>
<li><p><code>IT0</code>，外部中断寄存器</p>
</li>
<li><p><code>IT1</code>，外部中断寄存器</p>
</li>
<li><p><code>IT0/IT1=0</code>，低电平触发</p>
</li>
<li><p><code>IT0/IT1=1</code>，下降沿触发</p>
</li>
</ol>
<h3 id="中断寄存器">中断寄存器</h3><ol>
<li><code>ET0/ET1</code>，定时器中断使能寄存器，为1中断允许，为0不允许</li>
<li><code>EA</code>，总中断使能寄存器，为1中断允许，为0不允许</li>
<li><code>TR0/TR1</code>，定时器启动控制寄存器，为1时开始计数，为0时停止计数。</li>
</ol>
